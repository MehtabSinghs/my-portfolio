## 🚀 Quick Start

### Clone & Install
```bash
git clone https://github.com/MehtabSinghs/my-portfolio.git
cd my-portfolio
npm install
```

### Development
```bash
npm run dev
```
Visit `http://localhost:5173` to see the portfolio in action.

### Production Build
```bash
npm run build
```

## 🚀 Deployment

### GitHub Pages

1. Update `vite.config.js` to include base path if needed
2. Run `npm run build`
3. Push the `dist/` folder to GitHub Pages

### Netlify

1. Connect repository to Netlify
2. Set build command: `npm run build`
3. Set publish directory: `dist`

### Vercel

1. Connect repository to Vercel
2. Vercel auto-detects Vite configuration
3. Deploy with one click
